## Key Decisions

| Aspect | Decision |
|--------|----------|
| Decomposition axis | **Phase** (not step) — steps are UX display, phases are architectural boundaries |
| Store pattern | Vanilla `@Injectable` signal service scoped to wizard route (no NgRx) |
| Form location | Phase components own their forms; store owns committed arrays only |
| Shared forms issue | **Break apart:** Two separate add-item form instances (monster vs minion) or extract `AddSubItemFormComponent` |
| Preview bridging | Phase component exposes `previewData` computed signal; parent bridges to dossier via `viewChild()` |
| Persistence hook | Store owns `persist()`/`restore()` over sessionStorage; forms are transient only |
