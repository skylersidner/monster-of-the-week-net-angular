### 2026-08-02: Dark Theme Palette — Values, Badge Hue Preservation
**By:** Rosalina (Designer)
**What:** Produced `docs/theming/dark-theme-palette.md`, filling in a concrete light/dark value for every token in Yoshi's `theming-plan.md` Token Catalogue. Key calls:
- Dark base stays in the app's existing `slate` neutral family (not black/`zinc`) with a 3-step elevation ladder (`surface-sunken` slate-950 → `surface` slate-900 → `surface-raised` slate-800).
- `--color-accent` and `--color-danger` lighten in dark mode (`indigo-400`/`red-400`) with `--color-on-accent` flipping to `slate-900`, so a single token still works as both text-on-surface and a button fill (verified ~5.98:1 and ~6.45:1 respectively via hand-computed WCAG contrast).
- **The five type badges keep their light-mode hue family in dark mode** (monster=red, minion=orange, bystander=blue, location=green), inverted to deep-bg/light-text rather than reassigned to new hues — because they're a memorized cross-app legend and the theme toggle re-colors live with no reload, so a hue change between themes would make a badge appear to swap identity mid-toggle.
- Recommended overriding Yoshi's illustrative table-striping placeholder (`surface`/`surface-sunken` for zebra rows) with `--color-accent-subtle` for even rows — the former collapses to ~1.13:1 contrast in dark mode (imperceptible stripe), a risk Yoshi's own Phase 5 inspection point had already flagged as a concern.
**Why:** Values needed to unblock Yoshi's Phase 7 palette swap-in. Badge-hue call was explicitly left to Rosalina's judgment in the theming plan; documented reasoning in full since it's a user-facing recognizability decision, not just an aesthetic one.
**Open items flagged for Skyler/Yoshi sign-off (see doc's Open Questions):** the accent/danger lighten-and-flip pattern is a genuine brand-identity choice for buttons, not just a contrast fix; a new `--color-on-danger` token is needed (gap in the catalogue); the `monster-archetype` purple badge has no token at all (post-dates the catalogue); the mystery-badge and toast-brightness values are flagged as provisional/worth a look.
